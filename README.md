# نظام إدارة الطلبات الذكي (B2B SupplyWise)

نظام متكامل يربط بين الموردين وتجار التجزئة، يعتمد على تقنيات حديثة وذكاء أعمال للتنبؤ بسلوك الشراء وتنظيم سلاسل التوريد.

## ✨ المميزات الرئيسية
- **لوحة تحكم ذكية:** عرض الطلبات وحالاتها (قيد الانتظار، تم الشحن، مكتمل) بشكل لحظي.
- **تنبؤات الذكاء الاصطناعي (AI Insight):** خوارزمية مخصصة لتحليل نمط شراء التاجر والتنبؤ بموعد الطلب القادم.
- **تصدير البيانات:** دعم كامل لتصدير التقارير إلى ملفات Excel بضغطة زر.
- **نظام ثنائي الألوان:** دعم كامل للوضع الليلي (الملكي) ووضع النهار (الرسمي) باستخدام Tailwind v4.
- **قاعدة بيانات سحابية:** ربط مباشر مع Supabase لإدارة المستخدمين والبيانات بأمان عالٍ.

## 🛠 التقنيات المستخدمة (Tech Stack)
- **Frontend:** React.js, TypeScript.
- **Styling:** Tailwind CSS v4 (Modern Engine).
- **Backend/Database:** Supabase (PostgreSQL).
- **Icons:** Lucide-React.
- **State Management:** React Hooks (useState, useEffect).

## 🚀 كيف تبدأ؟
1. قم بعمل `Clone` للمستودع.
2. قم بتثبيت المكتبات: `npm install`.
3. قم بإنشاء ملف `.env` وربطه مع مشروعك في Supabase.
4. تشغيل المشروع: `npm run dev`.

## 📈 قاعدة البيانات (Database Schema)
- `orders`: تخزين تفاصيل الطلبات والأسعار.
- `order_items`: المنتجات داخل كل طلب.
- `profiles`: بيانات الموردين والتجار.
- `products`: كتالوج المنتجات المتاحة.
